# イベント募集 Bot（event-recruit-bot）

| 項目 | 内容 |
|---|---|
| バージョン | v1.0.0 |
| 状態 | 正式稼働中（台3 minase で pm2 稼働） |
| 稼働先 | 台3 minase |
| 実装 | TypeScript / discord.js v14 / Node.js 20 以上 |

Discord サーバーでのイベント参加募集を支援する Bot です。募集の投稿、
ボタンでの参加表明（RSVP）、締切リマインド、開始時の参加者スレッド
作成までを自動で行います。まぶさば（Discord コミュニティ）のイベント
運営用に作りました。

設計の判断記録は [DESIGN.md](DESIGN.md)、変更履歴は
[CHANGELOG.md](CHANGELOG.md) を参照してください。

## ✨ できること

- **募集の投稿**: `/event create` で募集用 Embed を投稿します。
  「参加 / 未定 / 不参加」ボタンが付き、押すたびに参加者リストがその場で
  更新されます。同じ区分をもう一度押すと取り消し、別の区分を押すと
  移動します。
- **締切リマインド**: 締切の1時間前になると、チャンネルへ「締切まもなく」の
  お知らせを投稿します（募集投稿へのリンク付き）。
- **開始通知とスレッド**: 開始時刻になると、参加者へのメンション付きで
  開始をお知らせし、募集投稿に公開スレッドを作成して参加者を招待します。
- **状態はファイルに保存**: 再起動しても募集内容・回答・送信済みフラグは
  失われず、リマインドや開始通知が重複することもありません。

## ⌨️ コマンド

| コマンド | 内容 |
|---|---|
| `/event create` | イベントの募集を投稿する |
| `/event list` | このサーバーの募集中イベント一覧 |
| `/event close <id>` | 募集を締め切る（作成者またはサーバー管理権限） |
| `/event cancel <id>` | イベントを中止する（同上） |

`/event create` のオプション:

| オプション | 必須 | 内容 |
|---|---|---|
| `title` | 必須 | イベント名（最大100文字） |
| `datetime` | 必須 | 開始日時。"2026-11-23 19:00" の形式で、**Asia/Tokyo（日本時間）**として解釈します |
| `description` | 任意 | 説明文（最大1000文字） |
| `deadline` | 任意 | 締切日時（同形式）。省略時は開始時刻が締切になります |

イベント ID は募集投稿の下部（フッター）に表示されます。`close` /
`cancel` の指定に使います。

## 🌍 環境変数

| 変数 | 必須 | 内容 |
|---|---|---|
| `DISCORD_TOKEN` | 必須 | Discord Bot のトークン |
| `CLIENT_ID` | 必須 | Discord アプリケーションのクライアント ID |
| `GUILD_ID` | 任意 | 設定すると、そのサーバーにだけコマンドを即時登録します（開発用） |
| `STATE_PATH` | 任意 | 状態ファイルのパス。既定は `data/state.json` |

実トークンは `.env`（`.env.example` を参照）で管理し、リポジトリには
含めません。

## 🚀 セットアップ

1. [Discord 開発者ポータル](https://discord.com/developers/applications) で
   アプリケーションを作成し、Bot を追加します。**特権インテントは不要**です
   （Guilds のみで動作します）。
2. Bot をサーバーへ招待します。スコープは `bot` と `applications.commands`、
   権限は「メッセージを送信」「埋め込みリンク」「スレッドの作成」があれば
   十分です。
3. `.env.example` を `.env` にコピーし、`DISCORD_TOKEN` と `CLIENT_ID` を
   設定します。開発中は `GUILD_ID` を設定するとコマンド登録が即時反映されます。
4. 起動します。コマンドは起動時に自動登録されます。

```bash
npm install
npm run build
npm start
```

登録だけを先に行いたい場合は `npm run deploy` が使えます。

## 🔄 pm2 での常駐

```bash
pm2 start ecosystem.config.cjs
pm2 startup   # 表示されたコマンドを実行
pm2 save
```

## 📋 仕様メモ

- 締切・開始の自動処理は1分間隔で確認します。若干の遅れ（最大1分程度）は
  ありますが、Bot が止まっていた間に過ぎた分も復帰後にまとめて処理します。
- 締切を過ぎても募集は自動では閉じません（`/event close` で締め切るか、
  開始時刻になれば開始通知に進みます）。ただし開始通知は、締切済みの
  イベントにも送られます。
- 中止したイベントにはリマインド・開始通知のどちらも送られません。
- 参加者リストの表示は区分ごとに最大40名までで、それ以上は「ほか N 名」と
  表示します（人数は正確に数えます）。
- 状態は `data/state.json` に保存します（環境変数 `STATE_PATH` で変更可）。
  終了したイベントは最大200件まで保持します。
